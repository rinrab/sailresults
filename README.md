# Sailing Results Scoring Calculator

## Run App

```
npm install # or `npm ci`
npx webpack
```

Then open ./index.html with firefox. Pull up F12 and you'll find a pop-up
suggesting to create a localhost server via "Local Mode". It should be present
in the recent versions. It doesn't really work by file protocol because of
cross origin restrictions. You could also use any of 348902 other tools for the
same job.
